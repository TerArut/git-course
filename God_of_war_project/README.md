# God of War — Python OOP Project

Учебный Python-проект по мотивам God of War. Реализована боевая система с персонажами, противниками и оружием с уникальными эффектами.

## Реализованный функционал

- **Персонажи:** Kratos и Atreus.
- **Противники:** Draugr и Troll.
- **ООП:** наследование, инкапсуляция, свойства (`@property`), переопределение методов.
- **Боевая система:** атака, получение урона, лечение, проверка состояния персонажа и определение победителя.
- **Оружие:** Leviathan Axe и Blades of Chaos.
- **Специальные эффекты оружия:**
  - Leviathan Axe — заморозка противника на один ход.
  - Blades of Chaos — дополнительный огненный урон.
- **Инвентарь:** добавление предметов и экипировка оружия.

Запускать из корневой директории проекта:

```bash
python -m god_of_war.battle
```
